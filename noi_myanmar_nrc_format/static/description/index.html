Myanmar NRC Format

This module adds Myanmar National Registration Card (NRC) format support to Sale Orders with proper validation and formatting.

Features

  • NRC Prefix Management - Configure State/Division codes (1-14)
  • Township Codes - Manage township codes per State/Division
  • NRC Types - Support for all NRC types (Naing, Pyuu, Ae, etc.)
  • Sale Order Integration - Full NRC field on Sale Orders
  • Automatic Formatting - Computes full NRC in standard format

NRC Format

Myanmar NRC follows the format:

[State/Division]/[Township]([Type])[Number]

Example: 12/TAMANA(N)123456

Configuration

Navigate to Sales > Configuration > NRC Configuration to manage:

  • NRC Prefixes (State/Division codes)
  • NRC Township Codes
  • NRC Types

Usage

On any Sale Order form, you can enter the customer's NRC information in the dedicated NRC fields. The full NRC will be automatically computed and displayed.

Pre-loaded Data

This module comes with pre-loaded data including:

  • All 14 State/Division prefixes
  • Sample township codes for Yangon and Mandalay
  • All standard NRC types
