Myanmar NRC Format

Version 16.0.1.0.0

Overview

This module provides complete management of Myanmar National Registration Card (NRC) format within Odoo. It allows you to capture and validate NRC numbers on Sale Orders following the official Myanmar NRC format.

NRC Format: [Prefix]/[Township Code]([Type])[Number]
Example: 12/YAKANA(N)123456

Features

  • Complete NRC Prefix management (14 States/Regions)
  • Township Code management with region association
  • NRC Type management (Citizen, Associate, Naturalized, Temporary)
  • Integration with Sale Orders
  • Automatic NRC number formatting
  • Dynamic township filtering based on selected prefix
  • Pre-loaded data for all 14 regions and major townships

Usage

  1. Install the module
  2. Go to Sales → NRC Format to manage NRC prefixes, township codes, and types
  3. Create or edit a Sale Order
  4. Fill in the NRC fields (Prefix, Township Code, Type, Number)
  5. The complete NRC will be automatically computed and displayed
