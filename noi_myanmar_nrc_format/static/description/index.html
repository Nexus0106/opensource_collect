Myanmar NRC Format

Odoo 18.0 Sales Myanmar

Myanmar National Registration Card (NRC) format integration for Odoo Sale Orders. Capture customer NRC information in the standard Myanmar format: 12/BaHaNa(N)123456

Features

  • Pre-configured 14 State/Division NRC Prefixes
  • Township codes linked to respective States/Divisions
  • NRC Types (Citizen, Associate, Naturalized, etc.)
  • Integrated NRC fields on Sale Order form
  • Auto-computed full NRC number
  • Dynamic township filtering based on selected prefix
  • Searchable by full NRC number

NRC Format

The Myanmar NRC follows the format:

[State/Division]/[Township Code]([Type])[6-digit Number]

Example: 12/BAHANA(N)123456
  • 12 - Yangon Region
  • BaHaNa - Botahtaung Township
  • N - Citizen
  • 123456 - Registration Number

Configuration

Access NRC configuration from: Sales → NRC Configuration

  • NRC Prefixes - Manage State/Division codes
  • NRC Township Codes - Manage township codes per State/Division
  • NRC Types - Manage citizenship types

Usage

On any Sale Order form, you will find NRC fields below the customer selection. Select the prefix, township, type, and enter the 6-digit number to compose the full NRC.

Technical Information

  • Models: nrc.prefix, nrc.township.code, nrc.type
  • Extended Model: sale.order
  • Dependencies: sale
