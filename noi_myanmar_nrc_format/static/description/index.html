Myanmar NRC Format

This module adds Myanmar National Registration Card (NRC) format support to Odoo Sales.

NRC Format

12/BAHANA(N)123456

State Code / Township Code (Type) Number

Features

NRC Prefix (State/Division Codes)

All 14 states and regions of Myanmar with their official codes (1-14).

NRC Township Codes

Township codes for each state/region following official Myanmar NRC format.

NRC Types

Support for all NRC citizenship types: N (Citizen), E (Associate), P (Naturalized), etc.

Sale Order Integration

Capture customer NRC information directly on sale orders with automatic full NRC computation.

Configuration

  • Go to Sales → Configuration → NRC Configuration
  • Manage NRC Prefixes, Township Codes, and Types
  • Pre-loaded with all 14 states and common township codes

Usage

  • Open any Sale Order
  • Fill in the NRC Information section
  • Select Prefix, Township, Type and enter the 6-digit number
  • Full NRC is automatically computed and stored
