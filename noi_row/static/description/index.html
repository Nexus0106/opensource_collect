Row Number in List View

by ZbyE Solution

Enhance usability by displaying clear row numbers in all Odoo list views — including one2many fields. Perfect for audits, referencing, and data clarity.

Features

  • Auto-numbered rows in all standard list views
  • Works seamlessly in one2many list fields (e.g., order lines, invoice items)
  • Smart placement: appears after checkbox in main lists, as first column in one2many
  • Clean "No." header with responsive width
  • Zero configuration — install and go!
